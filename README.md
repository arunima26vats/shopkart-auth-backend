# ShopKart Authentication Backend

A REST API authentication backend built using
Node.js, Express.js, MongoDB, Mongoose, bcrypt
and JWT.

## Features
- Customer registration and login
- Password hashing with bcrypt
- JWT authentication using HttpOnly cookies
- Protected customer profile route
- Logout
- Change password

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Setup

1. Clone the repository
2. Run npm install
3. Create a .env file with your configuration
4. Run npm start
